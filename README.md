# AI Assistants Proxy

Корпоративный сервис проксирования доступа к западным AI API для инженерной команды Организации. Обеспечивает безопасный, анонимный и отказоустойчивый доступ к AI-сервисам через единый статичный эндпоинт на территории РФ.

## Структура проекта

| Директория | Описание |
|------------|----------|
| [Clients/](Clients/) | Образцы клиентских конфигураций: расширения VSCode (Claude, Gemini), FoxyProxy для браузера, сценарии PowerShell. Адрес, порт и учётные данные подставляет оператор |
| [Servers/](Servers/) | Серверная инфраструктура (Ansible deployment, примеры конфигураций) |
| [docs/](docs/) | Документация проекта |

## Архитектура

Двухуровневая архитектура проксирования:

- **Access tier (РФ)** — проверка подлинности, авторизация, журналирование, кеширование. Переключение по виртуальному адресу (VRRP) — необязательная возможность, по умолчанию выключенная
- **Upstream tier (вне РФ)** — анонимный транспорт, минимальная конфигурация, доступ только с адресов access-узлов
- **Разрешение имён** — кеширующий резолвер на каждом узле, каскадом access → upstream → публичные резолверы; порт 53 upstream-узла открыт только адресам access-узлов
