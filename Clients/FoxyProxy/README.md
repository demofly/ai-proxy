# FoxyProxy: конфигурация и правила

`FoxyProxy.json` — образец импорта с вымышленными реквизитами, одним HTTP-профилем
и режимом **по шаблонам**. Рабочие экспорты содержат пароли: храните их вне Git.
Ansible не создаёт персональный JSON и не обновляет расширение браузера.

## Как устроены JSON-файлы

| Файл | Назначение |
| --- | --- |
| `FoxyProxy.json` | Готовый образец для импорта в расширение |
| `domains.json` | Вход генератора: исходные исключения пользователя и подтверждённые добавления |
| Приватный экспорт FoxyProxy | Действующие профили, реквизиты и настройки конкретного браузера |

Все три формата — строгий JSON, без комментариев и завершающих запятых.
`domains.json` в расширение не импортируется. В JSON обратная косая черта удваивается:
регулярное выражение `\.com` записывается строкой `"\\.com"`.

| Поле экспорта | Работа |
| --- | --- |
| `mode` | `pattern` включает выбор по правилам; режим конкретного прокси направляет через него все подходящие браузерные запросы |
| `data` | Упорядоченный массив профилей; каждый содержит собственные правила |
| `active` профиля | Участие профиля в выборе по шаблонам |
| `type` | В образце `http`; порт 443 сам по себе не делает транспорт к прокси HTTPS |
| `hostname`, `port` | Имя без схемы и порта; порт — отдельная строка |
| `username`, `password` | Отдельные поля, пароль без URL-кодирования |
| `include`, `exclude`, `tabProxy` | Включения, исключения и правила вкладок |
| `type`, `title`, `pattern`, `active` правила | Вид `regex`, короткое имя, выражение и включённость |
| `passthrough`, `container` | Глобальные исключения и назначения контейнеров; могут менять маршрут |
| `sync` | Синхронизация настроек браузера через хранилище Firefox; не объединяет правила профилей |
| `autoBackup` | Автоматический экспорт при сохранении настроек; копия может содержать пароли |
| `theme`, `commands` | Тема интерфейса и назначения профилей для команд расширения |
| `title`, `cc`, `city`, `color` профиля | Подпись, страна, город и цвет; не определяют сетевой маршрут |
| `pac`, `pacString` | URL и текст PAC для соответствующего типа профиля; в HTTP-образце пусты |
| `proxyDNS` | Управление DNS для SOCKS; не включает отдельный режим DNS у HTTP CONNECT |

В режиме по шаблонам используется первый подходящий активный профиль с учётом
исключений. Не совпавшие URL идут напрямую. `NO_PROXY` оболочки FoxyProxy не читает.
Серверные `allowed_domains` / `allowed_domain_patterns` действуют отдельно: браузерное
правило не разрешает запрос, запрещённый Squid.

## Исходные правила

`basis: "user"` в каталоге обозначает сохранённые исходные правила пользователя,
объединённые из его трёх прежних профилей. Это 22 исходных правила и 81 доменное имя,
включая ChatGPT, Claude, Gemini, Cursor, Microsoft, YouTube и личные исключения.
Проверка РКН к ним не применяется по решению владельца. В частности, широкие
`azure.com` и `cloudflare.com` сохранены как исходные исключения.

Для добавлений (`basis: "rkn"`) критерий — наличие домена в выбранной публичной
копии реестра `zapret-info/z-i`. Геоограничения поставщика и его список CDN сами
по себе не служат основанием. [Снимок, доказательства и ограничения проверки](registry-review.md).
Perplexity, Figma, Notion, TikTok, Pinterest и другие неподтверждённые добавления
не входят в новый каталог. Отсутствие в снимке не доказывает отсутствие всех видов блокировок.

Генератор выпускает пять непустых групп: `AI`, `Dev`, `Design`, `Social`, `Auth`.
Пустая категория `Media` оставлена в каталоге для распознавания и удаления её
прежнего управляемого правила при обновлении.

## Регулярные выражения

FoxyProxy использует JavaScript `RegExp`, а не PCRE. Сопоставляется только имя хоста
HTTP(S)/WS(S) URL, с допустимым портом и завершающей точкой. Домен из `domains`
охватывает также поддомены; запись `hosts` — только конкретное имя.
Генератор выносит общие суффиксы: `(?:chatgpt|openai)\.com`. Одинаковые домены и
поддомены, покрытые родительским правилом, удаляются. Длинная подпись видеосегмента
не сканируется выражением `(.*\.)*`; имя домена в пути или параметре URL не совпадает.

## Первичная настройка и обновление

Для первой настройки скопируйте `FoxyProxy.json` вне репозитория, замените подключение
и импортируйте копию через настройки расширения. Для существующей настройки сначала
экспортируйте её целиком, затем из корня проекта выполните (Python 3.10+):

```powershell
python Clients/FoxyProxy/rules.py --merge C:/Private/foxy-before.json --output C:/Private/foxy-updated.json
```

Выходной файл должен быть новым и находиться вне репозитория. Команда меняет только
`include` каждого профиля: обновляет управляемые группы, сохраняет их выключенное
состояние и пользовательские правила, упрощает покрытые каталогом конечные списки
доменов. Подключения, пароли, активность профилей, исключения, контейнеры и текущий
режим сохраняются. После импорта выберите **по шаблонам**, если нужна выборочная маршрутизация.
Для восстановления импортируйте исходный приватный экспорт.

Обновление каталога **не объединяет разные профили**. Для взаимного обогащения
сначала соберите объединение `include`, `exclude`, `tabProxy` по паре `(type, pattern)`,
согласуйте различающиеся `active`, затем скопируйте одинаковые массивы в нужные
профили. Их адреса, пароли и включённость должны остаться собственными. Такое
объединение может расширить маршрут трафика; проверяйте результат перед импортом.

При переходе с прежнего расширенного каталога генератор заменяет управляемые группы.
Домены, вручную скопированные из него в отдельные пользовательские правила, сохраняются:
их происхождение автоматически не определяется. Используйте экспорт до расширения
как основание для их отдельной сверки.

## Сопровождение

Добавляйте подтверждённые хосты с `basis: "rkn"`, ссылкой на снимок и
`registry_entries`. Для `domains` требуется запись `*.имя` в реестре; для `hosts` —
точная запись. Блокировка отдельной страницы чужого арендатора не разрешает включить
всю платформу Notion, Replit, Lovable или общий облачный домен.
Изменение исключений `basis: "user"` — отдельное явное решение владельца.

```powershell
python Clients/FoxyProxy/rules.py
python Clients/FoxyProxy/rules.py --check
python -m unittest discover -s Clients/FoxyProxy -p test_rules.py -v
python Clients/FoxyProxy/verify_registry.py C:/Private/dump.csv.gz
```

Последняя команда сверяет SHA256, дату и каждое добавление с зафиксированным снимком.
Проверки маршрутизации не доказывают доступность сайтов или качество проигрывания видео.
При зависании YouTube проверяйте запросы `googlevideo.com` в сетевой панели Firefox,
сравнивайте режимы по шаблонам / Proxy everything на одном узле и в одной сети.
Значок расширения не отражает все медиа- и фоновые запросы. Запишите время, хост и
ошибку до перезапуска служб. Настройки FoxyProxy действуют на Firefox; IDE, CLI,
мобильные приложения и WebRTC/UDP требуют собственной настройки.
