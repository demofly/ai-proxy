# FoxyProxy: правила для разработки и создания контента

`FoxyProxy.json` — готовый пример импорта с вымышленными реквизитами и режимом
**по шаблонам** (`mode: pattern`). Неподходящие под правила URL идут напрямую.
Для существующей настройки используйте слияние ниже: импорт готового примера
может заменить ваши профили.

`domains.json` содержит каталог сервисов и ссылки на первичные источники.
Дата проверки — 18 октября 2026 года. `domains` включает домен и его поддомены,
`hosts` — только конкретный хост. Каталог объединяет ресурсы, нужные для работы
из сетей с ограничениями доступа: ограничения РКН, региональные ограничения
поставщиков и зависимости приложений. Это рабочий список маршрутизации;
он не утверждает, что каждый перечисленный домен заблокирован РКН. Например,
[Notion ограничивает доступ из России со своей стороны](https://www.notion.com/help/restrictions-for-customers-based-in-russia).

| Группа | Основные сервисы |
| --- | --- |
| Ассистенты | ChatGPT/OpenAI, Claude, Grok, Gemini, AI Studio, NotebookLM, Google Labs, Copilot, Perplexity, Mistral, DeepL |
| Разработка и модели | GitHub/Copilot/Codespaces, Cursor, VS Code Marketplace, Hugging Face/Spaces/Xet, Replicate, fal, Replit, Lovable, Bolt, v0 |
| Генеративные медиа | Midjourney, Runway, Luma, Pika, Krea, Leonardo, Recraft, Ideogram, Suno, Udio, ElevenLabs, HeyGen |
| Дизайн и работа | Figma/Weave, Canva, Adobe/Firefly/Behance, Notion, Miro, Framer |
| Публикация и сообщества | YouTube, Instagram, Facebook, Threads, Messenger, TikTok, Pinterest, X/Twitter, Discord, LinkedIn, Medium, Telegram Web |
| Зависимости | Вход Google/Microsoft, проверка браузера Cloudflare/Arkose/hCaptcha/AWS WAF, выбранные хосты WorkOS, Stripe и файловых CDN |

Правила собраны в шесть групп, чтобы FoxyProxy не создавал отдельный `RegExp`
для каждого сайта на каждом запросе. Генератор убирает повторяющиеся домены
и поддомены, уже покрытые родительским доменом. Сопоставляется только хост URL,
включая HTTP(S), WS(S) и явный порт. Подписанные длинные URL видеосегментов
не сканируются выражением `(.*\.)*`.

## Обновление существующей настройки

1. Экспортируйте настройки FoxyProxy в JSON и сохраните экспорт вне репозитория.
2. Выполните слияние (Python 3.10 или новее, дополнительные пакеты не нужны):

   ```powershell
   python Clients/FoxyProxy/rules.py --merge C:/Private/foxy-before.json --output C:/Private/foxy-updated.json
   ```

3. Импортируйте `foxy-updated.json` через настройки FoxyProxy. Для выборочной
   маршрутизации должен быть выбран режим **по шаблонам**.

Слияние меняет только списки `include`: сохраняет реквизиты и адреса прокси,
активность профилей, исключения, правила вкладок, контейнеры и текущий режим.
Пользовательские правила остаются; старые правила с конечным списком доменов
упрощаются, если их домены уже покрыты каталогом. Произвольные выражения
и выключенные пользовательские правила сохраняются без изменений.
Группы `AI`, `Dev`, `Media`, `Design`, `Social`, `Auth` обновляются при повторном
слиянии; выключенная пользователем группа остаётся выключенной. Экспорты
с прежними названиями групп также поддерживаются. Выходной файл должен быть новым
и находиться вне репозитория, поскольку содержит пароли из исходного экспорта.

## Изменение каталога

Добавьте сервис в `domains.json` со ссылкой на его документацию или публичную
страницу, затем обновите пример и выполните проверки:

```powershell
python Clients/FoxyProxy/rules.py
python Clients/FoxyProxy/rules.py --check
python -m unittest discover -s Clients/FoxyProxy -p test_rules.py -v
```

Не добавляйте целиком `amazonaws.com`, `cloudfront.net`, `googleapis.com`,
`vercel.app`, `supabase.co` или всю зону `.ai`: это направит посторонний трафик
через небольшие прокси. Для общих CDN используются конкретные хосты, например
одна раздача CloudFront Runway. Figma отдельно требует общие сервисы `esm.sh`
и `jsdelivr.net`, поэтому они включены по её официальному списку.

Проверки покрывают медиа, WebSocket, авторизацию, разделение точных хостов
и доменов, ложные совпадения в пути/параметрах URL и сохранность настроек
при повторном слиянии. Они проверяют маршрутизацию, а не работу платных функций
в аккаунтах сервисов.

## Практические ограничения

Поставщики меняют CDN, используют подписанные ссылки на облачные хранилища,
а плагины Figma/Canva могут обращаться к собственным доменам. Для нового
непокрытого запроса добавляйте его фактический хост в каталог, предварительно
проверив назначение. Базовый набор не гарантирует все интеграции каждого сайта.

FoxyProxy управляет запросами Firefox. Настройки не применяются автоматически
к настольным IDE, CLI, мобильным приложениям или WebRTC/UDP: в частности,
доступ к веб-интерфейсу Discord не гарантирует голосовой тракт через HTTP-прокси.
Правила не меняют серверные лимиты памяти, но объём проксируемого трафика
зависит от числа пользователей и открытых приложений.
