# 9. Параметры настройки

Параметры задаются в инвентаре. Приведены умолчания; значения, при которых служба
ведёт себя иначе, отмечены в описании.

## Состав узла

| Параметр | Назначение | Умолчание |
|---|---|---|
| `proxy_role` | Уровень узла: доступа либо зарубежный | задаётся на узел |
| `enable_auth` | Проверка подлинности обращений | включена на уровне доступа |
| `enable_logging` | Журнал обращений | включён на уровне доступа, выключен на зарубежном |
| `enable_caching` | Кеширование ответов | включено на уровне доступа |
| `crowdsec_enabled` | Обнаружение вторжений | включено |
| `mtproxy_enabled` | Служба доступа к обмену сообщениями | включена на зарубежном уровне |
| `enable_keepalived` | Переключение виртуального адреса | выключено |

## Доступ

| Параметр | Назначение | Умолчание |
|---|---|---|
| `squid_port` | Порт приёма обращений | 443 |
| `allowed_domains` | Список разрешённых сервисов | не задан: сужения нет |
| `allowed_domain_patterns` | Список разрешённых сервисов по образцу имени | не задан |
| `allow_direct_fallback` | Запасной прямой выход при недоступности всех узлов второго уровня | выключен: прямой выход раскрыл бы целевому сервису адрес узла в стране |

## Тайминги

| Параметр | Что ограничивает | Умолчание |
|---|---|---|
| `read_timeout` | Простой соединения без передачи данных | 1 час |
| `client_lifetime` | Жизнь соединения целиком | 1 сутки |
| `client_idle_pconn_timeout` | Удержание неиспользуемого постоянного соединения | 60 секунд |

Предел жизни обязан быть строго больше предела простоя: иначе рвать соединение будет он,
и активный обмен погибнет наравне с бездействующим.

## Сроки хранения имён

| Параметр | Назначение | Умолчание |
|---|---|---|
| `squid_positive_dns_ttl` | Хранение разрешённого имени в кеше прокси-сервера | 6 часов |
| `squid_negative_dns_ttl` | То же для отрицательных ответов | 30 секунд |

Резолвер узла собственных сроков не навязывает: запись живёт столько, сколько объявил
владелец зоны.

## Шифрование участка между узлами

| Параметр | Назначение | Умолчание |
|---|---|---|
| `squid_transit_tls` | Шифрование участка между уровнями | включено |
| `squid_tls_sni` | Опознавательное имя участка; в системе имён разрешаться не обязано | задаётся |
| `squid_tls_term_port` | Порт снятия шифрования на зарубежном узле за маршрутизатором | 4444 |

## Журналы

| Параметр | Назначение | Умолчание |
|---|---|---|
| `sni_router_access_log` | Путь журнала маршрутизации | `/var/log/nginx/sni-router.log` |
| `sni_router_log_buffered` | Буферизовать запись журнала маршрутизации | включена |
| `squid_log_rotate_period` | Период ротации | ежедневно |
| `squid_log_rotate_keep` | Глубина хранения | 14 файлов |

## Память и пределы

| Параметр | Назначение | Умолчание |
|---|---|---|
| `mem_reserve_share` | Доля узла, оставляемая ядру при одиночном размещении | 0.25 |
| `mem_share_when_shared` | Доля узла при совместном размещении | 0.35 |
| `nginx_worker_connections` | Соединений на рабочий процесс маршрутизатора | 4096 |
| `squid_mgmt_port` | Порт снятия показателей на петлевом адресе; снаружи недостижим | 3129 |
| `squid_min_version` | Минимальная версия прокси-сервера | 5.7 |

## Разрешение имён

| Параметр | Назначение | Умолчание |
|---|---|---|
| `dns_servers` | Публичные серверы имён для зарубежного узла | три независимых адреса |
| `dns_extra_clients` | Кому ещё разрешено обращаться к резолверу | никому сверх узлов уровня доступа |
| `dns_resolver_dnssec` | Проверка подписей записей | включена |
