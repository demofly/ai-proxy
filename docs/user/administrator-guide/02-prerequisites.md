# 2. Подготовка узлов

## Управляющая машина

| Требование | Значение |
|---|---|
| Ansible | 2.9 и выше |
| Дополнения | `ansible.posix`, `community.general` |
| Доступ к узлам | По защищённой оболочке с правами администратора |

## Узлы

| Дистрибутив | Версия прокси из репозитория | Пригодность |
|---|---|---|
| Ubuntu 24.04 LTS | 6.14 | Рекомендуется |
| Debian 13 | 6.x | Пригоден |
| Debian 12 | 5.7 | Пригоден: все возможности службы проверены на этой версии |
| Ubuntu 22.04 LTS | 5.x | Требует подключения стороннего репозитория для версии 6.x |

Минимальная версия прокси-сервера — 5.7. Она проверяется при развёртывании: узел
с более старой версией отвергается с указанием найденной версии, а не разворачивается
молча.

**Системные требования:** Python 3.8 и выше, systemd, доступ с правами администратора.

## Память узла

Развёртывание считает бюджет памяти и **останавливается**, если сумма пределов служб
не помещается в узел. Это сделано намеренно: узел, где пределы не сходятся, уходит
в отказ под нагрузкой — то есть тогда, когда обслуживание и нужно.

| Размещение | Сколько доступно службам |
|---|---|
| Узел занят только этой службой | Память узла за вычетом четверти, оставленной ядру и системным службам |
| Узел делится с другой службой | Объявленная доля узла — 35 % (см. раздел о совместном размещении) |

Пределы отдельных служб — доли **выделяемого объёма**, но не ниже границ, при которых
служба работоспособна. Границы измерены: прокси не запускается при 64 МБ, обнаружение
вторжений потребляет около 150 МБ под нагрузкой.

При нехватке памяти развёртывание называет числа и перечисляет способы: увеличить память
узла, отключить необязательные составные части, понизить доли.

## Сеть

| Что | Куда | Зачем |
|---|---|---|
| Рабочие места | Узел уровня доступа | Обращения инженеров |
| Узел уровня доступа | Зарубежный узел | Цепочка обращений и разрешение имён |
| Зарубежный узел | Публичные серверы имён и целевые сервисы | Разрешение имён и сами обращения |

Порт разрешения имён на зарубежном узле закрыт для всех, кроме узлов уровня доступа.
Ограничение проверяется после развёртывания чтением действующих правил ядра, а не
только шаблона.
