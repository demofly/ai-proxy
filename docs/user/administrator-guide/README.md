# Руководство администратора

Развёртывание и обслуживание прокси-службы доступа к внешним AI-сервисам.

Руководство рассчитано на инженера, управляющего инфраструктурой: он правит инвентарь,
запускает развёртывание, ведёт учётные записи, читает журналы и разбирает отказы.
