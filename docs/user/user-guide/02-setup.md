# 2. Настройка рабочего места

Адрес, порт и реквизиты берутся у администратора. Ниже `АДРЕС`, `ПОРТ`, `ИМЯ`, `ПАРОЛЬ` —
подстановки.

## Переменные окружения

Большинство средств разработки и командных утилит читают переменные окружения.

**Linux и macOS** — в файл настройки оболочки:

```bash
export HTTP_PROXY="http://ИМЯ:ПАРОЛЬ@АДРЕС:ПОРТ"
export HTTPS_PROXY="http://ИМЯ:ПАРОЛЬ@АДРЕС:ПОРТ"
export NO_PROXY="localhost,127.0.0.1,.внутренний-домен"
```

**Windows, PowerShell** — в профиль:

```powershell
$env:HTTP_PROXY  = "http://ИМЯ:ПАРОЛЬ@АДРЕС:ПОРТ"
$env:HTTPS_PROXY = "http://ИМЯ:ПАРОЛЬ@АДРЕС:ПОРТ"
$env:NO_PROXY    = "localhost,127.0.0.1,.внутренний-домен"
```

Перечень исключений обязателен: без него через внешнюю службу пойдут и обращения
к внутренним ресурсам, которые она не обслуживает.

## Среды разработки

| Среда | Где задаётся |
|---|---|
| VS Code | Параметры → `http.proxy`; либо переменные окружения, если среда запускается из оболочки |
| Среды JetBrains | Настройки → Внешние соединения → Прокси, с указанием реквизитов |
| Командные утилиты | Переменные окружения выше |

## Firefox и клиентские JSON

Для FoxyProxy импортируется заполненная приватная копия `FoxyProxy.json`,
для VS Code ключи из образцов Claude/Gemini объединяются с существующими
пользовательскими настройками. `domains.json` — вход генератора, не файл импорта.
Порядок и поля описаны в [руководстве клиентов](../../../Clients/README.md)
и [инструкции FoxyProxy](../../../Clients/FoxyProxy/README.md).

Для выборочного маршрута включите режим **по шаблонам**. Режим конкретного прокси
направляет через него все подходящие запросы браузера. Исключения FoxyProxy
задаются отдельно от `NO_PROXY` оболочки. Не заменяйте свою конфигурацию публичным
образцом без предварительного экспорта: в нём вымышленные реквизиты.

## Проверка

```bash
curl -v --max-time 25 --proxy http://АДРЕС:ПОРТ \
  --proxy-user 'ИМЯ:ПАРОЛЬ' https://example.com/
```

В Windows используйте `curl.exe`, чтобы не вызвать одноимённую команду PowerShell.
Выбирайте разрешённый серверными ACL HTTPS-адрес. `200 Connection established`
означает, что прокси открыл CONNECT-туннель. Конечный HTTP-код относится уже к
целевому сайту: корень API может штатно возвращать 401, 403 или 404.
`407 Proxy Authentication Required` означает отказ проверки реквизитов прокси.
Код `000` означает отсутствие конечного HTTP-ответа; причину определяют по
выводу `-v` и коду завершения curl. Перед передачей вывода удалите реквизиты.

## Если пароль содержит особые символы

Символы `@`, `:`, `/` в строке адреса разделяют её части и ломают разбор. Такой пароль
записывается в кодировке процентов либо задаётся отдельным полем в настройках среды,
а не строкой адреса.
