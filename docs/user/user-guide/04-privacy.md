# 4. Что о вас записывается

Раздел отвечает на вопрос, который стоит задать любому пользователю посреднической
службы: что она о вас знает.

## Записывается

| Что | Где | Зачем |
|---|---|---|
| Время обращения | Журнал узла уровня доступа | Разбор происшествий, расследование инцидентов |
| Имя вашей учётной записи | Там же | Кто обращался |
| Адрес вашей машины | Там же | Откуда обращались |
| Имя целевого сервиса | Там же | К чему обращались |
| Объём переданного | Там же | Учёт нагрузки |

## Не записывается

- **Содержимое HTTPS внутри CONNECT.** TLS устанавливается между клиентом и сайтом;
  перехват TLS в проекте не настроен. Прокси видит адрес назначения, время и объём.
  Обычный HTTP передаётся без такой защиты: прокси может видеть URL, обрабатывать
  содержимое и кешировать ответы.
- **Пароль в штатном журнале обращений.** Серверный файл учётных записей хранит хеш.
  Клиентский JSON, URL прокси и экспорт FoxyProxy содержат исходный пароль:
  храните их приватно. HTTP-прокси использует Basic-аутентификацию; при
  `http://` участок клиент → прокси сам по себе не защищён TLS, даже если порт 443.

## Что видит целевой сервис

Обращение приходит к нему от зарубежного узла службы. Адрес вашей машины и адрес узла
внутри страны ему недоступны, признаки прохождения через прокси сняты.

При этом сам сервис видит содержимое обмена: шифрование защищает от посредников,
а не от адресата. Учётные данные, которые вы вводите в среде разработки, идут сервису
внутри защищённого соединения с ним. Логин и пароль самого прокси относятся к
проверке доступа на access-узле и не являются реквизитами целевого сайта.

## Срок хранения

Записи журналов вращаются: старые файлы вытесняются новыми, глубина хранения задана
администратором (по умолчанию — четырнадцать суточных файлов).
