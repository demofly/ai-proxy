# C3-SA-001-API — приём обращений от потребителей

**Последняя правка AI:** 2026-10-19

| Параметр | Значение |
|---|---|
| **Компонент** | [C3-SA-001](../../C3/C3-SA-001.md) — прокси уровня доступа |
| **Класс** | Integration |
| **Протокол** | HTTP-прокси (RFC 9110) с туннелированием методом CONNECT |
| **Требования** | [C2-FR-001](../../C2/C2-FR-001.md), [C2-FR-002](../../C2/C2-FR-002.md), [C2-FR-003](../../C2/C2-FR-003.md) |

## Точка подключения

| Режим узла | Адрес и порт | Условие |
|---|---|---|
| Прокси слушает сам | `0.0.0.0:{proxy_port}` | `behind_nginx` выключен и MTProxy выключен |
| Прокси за маршрутизатором | `127.0.0.1:{squid_local_port}` с обязательным протоколом PROXY | Иначе; снаружи узел принимает на 443, имя разбирает маршрутизатор |

Во втором режиме прямое обращение к петлевому порту от постороннего невозможно:
разрешён единственный источник — сам узел, и заголовок протокола PROXY обязателен.

## Что обязан прислать потребитель

1. Запрос `CONNECT {хост}:{порт} HTTP/1.1`.
2. Заголовок `Proxy-Authorization` со схемой Basic — при включённой проверке подлинности
   (умолчание для уровня доступа). Учётные записи хранятся хешами bcrypt.

## Что возвращается

| Ответ | Когда |
|---|---|
| `200 Connection Established` | Проверка подлинности пройдена, домен разрешён, вышестоящий узел ответил |
| `407 Proxy Authentication Required` | Заголовок проверки подлинности отсутствует либо реквизиты неверны |
| `403 Forbidden` | Заданы списки доменов, и запрошенный в них не входит |
| `503 Service Unavailable` | Все вышестоящие узлы недоступны, а запасной прямой выход запрещён |

Незаданные списки доменов **не** дают отказа: сужения нет, и аутентифицированному
потребителю доступен любой домен ([C2-FR-003](../../C2/C2-FR-003.md)).

## Свойства обмена

- **Содержимое туннеля недоступно прокси:** внутри установленного соединения идёт
  сквозное шифрование потребителя с целевым сервисом.
- **Предел простоя** — 1 час без передачи данных в обе стороны; таймер переармируется
  каждой порцией, поэтому длительность обмена не ограничена. Абсолютный предел жизни
  соединения — сутки.
- **Выбор вышестоящего узла** — по хешу имени потребителя: один и тот же потребитель
  устойчиво уходит на один узел, пока тот жив.

## Совместимость

Изменение точки подключения, схемы проверки подлинности либо состава кодов ответа
ломает потребителей и требует согласования: клиентские конфигурации раздаются вручную
([Ideas.md](../../Ideas.md), GAP-059), и молчаливая смена контракта обнаружится отказом
у каждого потребителя по отдельности.
