## Обмен между узлами пары

| Параметр | Значение | Условие согласованности |
|---|---|---|
| Виртуальный адрес | `keepalived_vip` с префиксом `keepalived_vip_prefix` | Одинаков у обоих узлов пары |
| Группа | `keepalived_vrid` (умолчание 51) | Одинакова внутри пары, различна у несвязанных пар одной сети |
| Имя узла в объявлениях | `keepalived_router_id` | Опознавательное, в журнале и трассировке обмена |
| Роль и приоритет | `keepalived_state`, `keepalived_priority` | Задаются на узел |
| Пароль обмена | `keepalived_auth_pass` | Одинаков в паре; без него объявления принимаются от кого угодно в сети |

Совпадение группы у двух несвязанных пар в одной сети приводит к тому, что они считают
друг друга участниками одной группы, и виртуальный адрес переезжает непредсказуемо.

## Проверка работоспособности

Сценарий проверяет, жива ли служба прокси, и при её отказе пытается перезапустить —
не чаще, чем раз в `keepalived_restart_cooldown` секунд. Выдержка нужна, чтобы
неустранимый отказ не превратился в непрерывный цикл перезапусков: без неё узел
удерживал бы виртуальный адрес, не обслуживая обращений.
