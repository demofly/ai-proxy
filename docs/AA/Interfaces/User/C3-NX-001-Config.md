# C3-NX-001-Config — точки расширения маршрутизатора

**Последняя правка AI:** 2026-08-30T15:37:22Z

| Параметр | Значение |
|---|---|
| **Компонент** | [C3-NX-001](../../C3/C3-NX-001.md) — маршрутизатор по имени SNI |
| **Класс** | User (конфигурационный интерфейс) |
| **Потребитель** | Соседний проект, размещённый на том же узле |
| **Требования** | [C2-CN-002](../../C2/C2-CN-002.md) |

Это контракт совместного размещения: узел один, служба маршрутизации одна, и порт 443
делится между проектами. Контракт определяет, **как сосед добавляет своё, не трогая чужого**.

## Что предоставляется

| Каталог | Контекст службы | Что кладёт сосед |
|---|---|---|
| `/etc/nginx/stream.d/sni-map.d/*.conf` | Карта имён внутри маршрутизатора | Строки «имя → цель» для своих имён |
| `/etc/nginx/stream.d/*.conf` | Потоковый | Собственные объявления целей и слушателей |
| `/etc/nginx/stream.d/router.d/*.conf` | Внутри слушателя порта 443 | Вставки, действующие на все соединения порта |
| `/etc/nginx/conf.d/*.conf` | HTTP | Собственные виртуальные хосты и зоны ограничений |

Имя файла соседа несёт его префикс. Чужих файлов ведущий проект не читает и не правит.

## Что принадлежит ведущему и соседом не изменяется

| Объект | Почему |
|---|---|
| `/etc/nginx/stream.d/00-sni-router.conf` | Единственный слушатель порта 443; две редакции означали бы, что каждое развёртывание возвращает свою |
| `worker_connections`, `worker_rlimit_nofile` в `nginx.conf` | Строка в файле одна, и значение обязано покрывать нагрузку всех проектов узла |

Сосед разворачивает собственную редакцию маршрутизатора **только** при его отсутствии —
иначе порт 443 не слушает никто. Такая редакция временная и обязана не ломать соседей:
предел простоя в ней не ниже, чем требует самая долгая цепочка узла, а специфичные
ограничения числа соединений в неё не входят.

## Инвариант, который сосед обязан соблюдать

Имена в карте не пересекаются. Совпадение имени у двух проектов означает, что
соединение уйдёт к тому, чей файл прочитан позже, — молча и без признака ошибки.
