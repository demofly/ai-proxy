## Контракт совместного размещения

Источники объявляются **файлом на проект** в `/etc/crowdsec/acquis.d/`; общий
`acquis.yaml` не перезаписывается. Прежде роль писала в общий файл и затирала источники
соседа при каждом своём прогоне.

## Объявляемые источники

| Файл | Метка | Разбирается ли |
|---|---|---|
| `/var/log/squid/access.log` | `squid` | **Нет.** Парсера для этой метки не существует — проверено сплошным поиском по индексу хаба; записи молча отбрасываются. Источник оставлен как заготовка: он станет рабочим, когда парсер появится |
| Журнал маршрутизации (`sni_router_access_log`) | `nginx` | Да, парсером `crowdsecurity/nginx-logs`. Вид записи подогнан под него; это действующий источник обнаружения по обращениям |
| `/var/log/auth.log` и журнал службы доступа | `syslog` | Да, коллекцией `crowdsecurity/linux` |

## Требование к виду записи

Запись журнала маршрутизации обязана совпадать по виду с журналом обращений HTTP:
адрес клиента, время в принятом формате, строка запроса, код, объём, два поля в кавычках.
Отклонение от вида — не ошибка конфигурации, а молчаливая потеря разбора: события
перестают порождаться, а служба продолжает работать.
