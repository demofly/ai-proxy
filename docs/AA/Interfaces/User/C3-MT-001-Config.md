## Точка подключения

| Узел | Что слушает | Как попадает обращение |
|---|---|---|
| Уровня доступа | `127.0.0.1:{mtproxy_relay_port}` | Маршрутизатор направляет по имени `mtproxy_fake_tls_domain`, затем ретрансляция на зарубежный узел |
| Зарубежный | `127.0.0.1:{mtproxy_tls_port}` — терминатор, за ним демон на `{mtproxy_local_port}` | Маршрутизатор направляет по имени `mtproxy_hostname` |

Наружу оба узла принимают только на 443: собственных внешних портов у MTProxy нет.

## Реквизиты потребителя

Секрет в шестнадцатеричной записи (`mtproxy_secret`); при пустом значении порождается
на узле при первом развёртывании и далее не меняется. Имя маскировки
(`mtproxy_fake_tls_domain`) обязано совпадать у потребителя и в карте имён узла: при
расхождении соединение уйдёт бэкенду по умолчанию, где протокол не разбирается.

## Ограничение

Число одновременных подключений с одного адреса — `mtproxy_max_connections`.
