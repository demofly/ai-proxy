# DE-BD-001 — Решения о блокировке (CrowdSec)

**Последняя правка AI:** 2026-08-29T07:40:00Z

## Описание

Решения о блокировке — записи о том, какие адреса и на какой срок закрыты системой обнаружения вторжений. Существуют в двух видах одновременно: как записи местной базы CrowdSec (источник истины) и как элементы множества в правилах ядра, куда их переносит применитель решений.

Сущность отделена от списков управления доступом ([DE-AC-001](DE-AC-001.md)) намеренно: те задаются оператором через инвентори и меняются только развёртыванием, а эти появляются и исчезают сами, без участия человека, и при повторном развёртывании не восстанавливаются.

## Атрибуты

| Атрибут | Тип | Описание | Обязательность |
|---|---|---|---|
| value | адрес IPv4 либо диапазон | К кому применяется решение | Обязательный |
| scenario | string | Сценарий обнаружения, породивший решение | Обязательный |
| duration | интервал | Срок действия; по истечении решение снимается | Обязательный |
| origin | enum {crowdsec, cscli, capi} | Источник: местное обнаружение, ручная команда либо общая база сообщества | Обязательный |

## Хранилища

### 1. Местная база CrowdSec

| Параметр | Значение |
|---|---|
| **Путь** | `/var/lib/crowdsec/data/` |
| **Формат** | База SQLite, создаётся при установке пакета |
| **Владелец** | Служба CrowdSec |
| **Просмотр** | `cscli decisions list` |

### 2. Правила ядра

| Параметр | Значение |
|---|---|
| **Расположение** | Таблица `ip crowdsec` в nftables, приоритет `filter - 10` |
| **Формат** | Множество адресов с истечением срока |
| **Владелец** | Юнит `crowdsec-firewall-bouncer` (пакет `crowdsec-firewall-bouncer-nftables`) |
| **Существование** | Только в памяти ядра: в `/etc/nftables.conf` эти записи не попадают, и развёртывание их не трогает |

Разделение важно для понимания последствий: обновление правил экрана развёртыванием заменяет **собственную** таблицу проекта и не задевает таблицу применителя решений, поэтому блокировки переживают повторный прогон плейбука. Проверено на стенде.

## Жизненный цикл

| Стадия | Действие | Актор | Инструмент |
|---|---|---|---|
| **Create** | Сценарий срабатывает по записям журналов | Агент CrowdSec | Сценарии установленных наборов |
| **Store** | Запись в местную базу | CrowdSec | SQLite |
| **Apply** | Перенос в правила ядра | Применитель решений | nftables |
| **Dispose** | Снятие по истечении срока либо командой | CrowdSec | `cscli decisions delete` |

Записи не переживают удаление базы: при переустановке узла решения теряются, и это допустимо — они восстанавливаются обнаружением заново.

## Безопасность

| Параметр | Значение |
|---|---|
| **Уровень конфиденциальности** | Низкий: адреса нарушителей, а не пользователей |
| **Ложное срабатывание** | Адреса узлов проекта внесены в белый список (`whitelist-infrastructure.yaml`), чтобы кластер не заблокировал сам себя |
| **Обмен с сообществом** | Оповещения уходят в общую базу CrowdSec; содержимое обращений в них не входит |
