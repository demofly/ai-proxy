# DE-CA-001 — Кеш ответов Squid

**Последняя правка AI:** 2026-08-29T07:40:00Z

## Описание

Кеш ответов — дисковое и оперативное хранилище тел ответов, которые Squid переиспользует при повторных обращениях. Разворачивается только на access-уровне и только при включённом `enable_caching`; на upstream кеширование отключено директивой `cache deny all`, поскольку тот уровень служит анонимным транспортом.

Практическая польза кеша ограничена: основной трафик — туннели `CONNECT` со сквозным шифрованием ([DE-TR-001](DE-TR-001.md)), а их содержимое кешированию не поддаётся в принципе. Кешируются лишь обычные HTTP-ответы, если такие обращения есть.

## Атрибуты

| Атрибут | Тип | Описание | Обязательность |
|---|---|---|---|
| url | string | Адрес, по которому запись найдена | Обязательный |
| body | двоичные данные | Тело ответа | Обязательный |
| headers | набор строк | Заголовки ответа, включая сроки годности | Обязательный |
| stored_at | datetime | Время помещения в кеш | Обязательный |

## Хранилище

| Параметр | Значение |
|---|---|
| **Путь (диск)** | `/var/spool/squid/` |
| **Формат** | Хранилище `ufs`: два уровня каталогов, 16 и 256 |
| **Объём (диск)** | 100 МБ, значение задано в шаблоне |
| **Предел объекта (диск)** | 50 МБ |
| **Объём (память)** | 25 % предела памяти службы Squid в бюджете узла |
| **Предел объекта (память)** | 512 КБ |
| **Права** | Каталог принадлежит `proxy:proxy`, создаётся при инициализации кеша |
| **Инициализация** | `squid -z` при первом развёртывании |
| **Компонент** | [C3-SA-001](../../C3/C3-SA-001.md) — Squid Access Proxy |

## Жизненный цикл

| Стадия | Действие | Актор | Инструмент |
|---|---|---|---|
| **Create** | Запись ответа, допускающего кеширование | Squid | `cache_dir`, `cache_mem` |
| **Use** | Выдача из кеша при повторном обращении | Squid | Поиск по адресу |
| **Update** | Замена записи при устаревании | Squid | Заголовки сроков годности |
| **Dispose** | Вытеснение при заполнении либо очистка каталога | Squid | Политика вытеснения; при отключении кеширования каталог очищается развёртыванием |

## Безопасность

| Параметр | Значение |
|---|---|
| **Уровень конфиденциальности** | Средний: тела ответов могут содержать рабочие данные |
| **Расположение** | Только access-узел на территории РФ |
| **Отключение** | При `enable_caching: false` выпускается `cache deny all`, каталог не создаётся |
| **Очистка** | Развёртывание с выключенным кешированием очищает каталог журналов и кеша |
