## Конвенции карточек

Единые для всех слоёв и представлений; при правке артефакта обе применяются к нему сразу.

| Элемент | Где размещается | Назначение |
|---|---|---|
| **Отметка последней правки** — строка `**Последняя правка AI:** {дата и время в UTC, до секунд}` | сразу под заголовком первого уровня | утверждение, что содержимое сверено с источником истины на указанный момент; более поздняя дата изменения файла означает стороннюю правку и требует повторной сверки |
| **Таблица уровня соответствия** — секция `## Статус соответствия` (Дата, Уровень, Обоснование, Корректирующее действие) | последняя секция карточки | степень выполнения критериев по шкале 0–5; в реестре слоя тому же значению соответствует столбец «Уровень» |

Обоснование уровня пишется по существу сверки — какие именно источники сопоставлялись; общая формулировка делает повторную проверку невоспроизводимой. Слои, где обе конвенции ещё не применены, перечислены в [Ideas.md](Ideas.md).
