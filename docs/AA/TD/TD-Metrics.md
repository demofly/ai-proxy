# TD-Metrics — Каталог метрик

**Последняя правка AI:** 2026-08-29T07:28:20Z

## Описание

Числовые показатели работы системы: что измеряется, чем снимается и какое значение считается
приемлемым. Столбец источника называет конкретную команду — если инструмент на узлах
недоступен, это указано прямо, чтобы показатель не считался снимаемым.

Событийная сторона — [TD-Events.md](TD-Events.md); журналы — [TD-Logs.md](TD-Logs.md).

## Метрики

| ID | Метрика | Тип | Источник | ФО | Описание | Целевое значение |
|---|---|---|---|---|---|---|
| MET-01 | Частота обращений | counter | Squid: журнал обращений — при включённом журналировании; одномоментное число соединений журнал не даёт, для него нужен запрос к менеджеру на порту управления; пакет `squidclient` ставится развёртыванием (в поставку `squid` он не входит) | ФО-01 | Число обращений за единицу времени, выводимое подсчётом записей | — (информационная) |
| MET-02 | cache_hit_ratio | gauge | Squid: `squidclient -h 127.0.0.1 -p {squid_mgmt_port} mgr:info`; пакет ставится развёртыванием, иного способа снять метрику нет | ФО-01 | Процент запросов, обслуженных из кэша | ≥ 10% (для кешируемого контента) |
| MET-03 | response_time_ms | histogram | Squid: поле времени отклика в журнале обращений | ФО-01 | **Полное** время обработки, включая ожидание ответа от сервиса; собственная задержка прокси отсюда прямо не извлекается | Целевого значения нет: прежнее «≤ 50 мс добавленной задержки» этой величине не соответствует — [Ideas.md](../Ideas.md), GAP-148 |
| MET-04 | Неудачные попытки подлинности | counter | Squid: записи со статусом 407 в журнале обращений — при включённых журналировании и проверке подлинности | ФО-02 | Количество неудачных попыток аутентификации в минуту | < 10 (порог CrowdSec) |
| MET-05 | crowdsec_bans_total | counter | CrowdSec (cscli metrics) | ФО-02 | Общее количество заблокированных IP | — (информационная) |
| MET-06 | Переключения владельца виртуального адреса | counter | Системный журнал Keepalived — **только при включённом `enable_keepalived`**; в образце инвентори он выключен, и метрика тогда не существует | ФО-03 | Число смен владельца адреса | 0 в нормальном режиме |
| MET-07 | Доступность вышестоящих узлов | gauge | Squid: состояние пиров через `squidclient -h 127.0.0.1 -p {squid_mgmt_port} mgr:server_list` либо записи о смене состояния пира в журнале работы | ФО-03 | Признак доступности каждого узла | 1 (все доступны) |
| MET-08 | Состояние службы | gauge | systemd: `systemctl is-active` | ФО-06 | Состояние каждой службы. Прежнее имя обещало время работы — измеритель его не даёт; для длительности нужен `systemctl show -p ActiveEnterTimestamp` | active |
| MET-09 | dns_cache_hits | counter | **недоступна**: требует включения `remote-control` в конфигурации резолвера, которого сейчас нет | ФО-07 | Доля запросов, отвеченных из кеша узла | — |
| MET-10 | dns_denied_queries | counter | счётчики отбрасывающего правила экрана | ФО-07 | Обращения к порту 53 с посторонних адресов | рост означает сканирование |
| MET-11 | service_memory_bytes | gauge | systemd (`systemctl show -p MemoryCurrent`) | ФО-06 | Текущее потребление памяти службой относительно её предела | ниже мягкого порога (80 % предела) |
