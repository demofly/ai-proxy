## Описание

Проект поставляет статические образцы клиентских настроек и локальный генератор
правил FoxyProxy. Ansible разворачивает серверы и не создаёт персональные клиентские
файлы из inventory. Адрес, порт и учётные данные подставляет оператор; автоматизация
этой подстановки остаётся открытым разрывом GAP-059.

| Артефакт | Контракт | Применение |
| --- | --- | --- |
| `Clients/Claude/settings.json` | `claudeCode.environmentVariables`: массив объектов `name` / `value` | Объединить с пользовательскими настройками VS Code для Claude Code |
| `Clients/Gemini/settings.json` | `http.proxy`, `geminicodeassist.project` | Объединить с настройками VS Code для Gemini Code Assist |
| `Clients/FoxyProxy/FoxyProxy.json` | Полный экспорт: `mode`, `data`, профили и массивы правил | Заполнить приватную копию и импортировать в расширение |
| `Clients/FoxyProxy/domains.json` | Каталог доменов, оснований и источников | Вход `rules.py`; в расширение не импортируется |
| `Clients/PowerShell/register-vars.ps1` | Пользовательские `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY` | Изменяет окружение для новых процессов Windows |
| `Clients/PowerShell/unregister-vars.ps1` | Удаление пользовательских переменных | Текущие процессы сохраняют старое окружение до перезапуска |

Статические файлы — строгий JSON, настройки VS Code допускают JSONC.
Фрагменты IDE не заменяют весь пользовательский файл и не предназначены для
`.claude/settings.json` или Gemini CLI. Проверка TLS-сертификатов не отключается.
В URL реквизиты кодируются процентами; в отдельных полях FoxyProxy — обычным текстом.
`http://…:443` задаёт HTTP-прокси, а TLS сайта проходит через CONNECT.

### Выборочная маршрутизация браузера

`rules.py` строит JavaScript RegExp только для хоста URL. Общие суффиксы вынесены,
домены дедуплицированы. `domains` охватывает поддомены, `hosts` задаёт точное имя.
В текущем каталоге пять непустых групп: `AI`, `Dev`, `Design`, `Social`, `Auth`.
Не совпавшие URL в режиме `pattern` идут напрямую. Серверные ACL и браузерный
каталог независимы; изменение одного не обновляет другой.

Исходные правила пользователя сохранены. Добавления требуют подтверждения в
зафиксированной публичной копии реестра РКН; дата снимка, ограничения и точные
основания описаны в [реестре доменов](../../../Clients/FoxyProxy/registry-review.md).
Геоограничение поставщика само по себе не является основанием добавления.

`rules.py --merge INPUT --output OUTPUT` обновляет только `include` каждого
профиля, сохраняет реквизиты, активность, режим, исключения и пользовательские
правила. Выход должен быть новым приватным файлом вне репозитория. Между разными
профилями правила автоматически не объединяются; `sync` FoxyProxy означает
синхронизацию хранилища браузера, а не взаимное обогащение профилей.

## Критерии приёмки

| № | Критерий | Проверка | Целевое значение |
| --- | --- | --- | --- |
| 1 | Образцы JSON синтаксически корректны | Парсинг каждого файла | Успех |
| 2 | Публичный FoxyProxy соответствует каталогу | `python Clients/FoxyProxy/rules.py --check` | Код 0 |
| 3 | Правила ограничены именем хоста, точные хосты не расширены | `test_rules.py` | Все проверки проходят |
| 4 | Слияние сохраняет приватные настройки и идемпотентно | `test_rules.py` | Равенство полей вне `include`, повтор без изменений |
| 5 | Добавления подтверждены выбранным снимком | `verify_registry.py` с закреплённым gzip | SHA256, дата и все записи совпадают |
| 6 | Клиент получает рабочее подключение | Заполнение копии и ручная проверка в приложении | Отдельная эксплуатационная проверка |

## Доказательство реализации

### Конструктивное

Артефакты лежат в `Clients/`. Генератор `Clients/FoxyProxy/rules.py` работает
локально на Python 3.10+ без сторонних пакетов. Его вход — `domains.json` и,
при слиянии, приватный экспорт. Доступа к Firefox-профилю у генератора нет.
Ansible-шаблонов персональных JSON в текущем развёртывании нет.

### Аналитическое

Раздельные контракты IDE, браузера и окружения исключают перенос несовместимых
ключей. Явная история происхождения доменов позволяет проверять расширение списка,
сохраняя пользовательские исключения. Автоматическая подстановка inventory не заявляется.

| Устаревание выбранной копии РКН | Закреплённая версия, дата и явное указание возраста снимка |
