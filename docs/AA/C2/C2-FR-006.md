# C2-FR-006 — MTProxy для Telegram

**Последняя правка AI:** 2026-08-29T05:40:53Z

## Ссылки

- Родительские требования C1: [C1-BC-001](../C1/C1-BC-001.md), [C1-BC-003](../C1/C1-BC-003.md)
- Дочерние требования C3: [C3-MT-001](../C3/C3-MT-001.md), [C3-NX-001](../C3/C3-NX-001.md)

## Описание

Система предоставляет MTProxy-сервис для доступа к Telegram через upstream-ноды. MTProxy обеспечивает обход DPI-блокировок благодаря маскировке трафика под стандартный TLS (fake-TLS). Маршрутизация MTProxy-трафика осуществляется через nginx SNI Router, разделяющий порт 443 с другими сервисами ([C2-CN-002](C2-CN-002.md)).

### Компоненты

1. **mtg v2** — реализация MTProxy протокола (Go-бинарник).
2. **nginx SNI Router** — маршрутизирует TLS-трафик по SNI на MTProxy или другие backend.

### Механизм работы

![MTProxy fake-TLS маскировка и маршрутизация через nginx SNI](../ADR/diagrams/ADR-000005-mtproxy-flow.svg)

> Исходник: [../ADR/diagrams/ADR-000005-mtproxy-flow.puml](../ADR/diagrams/ADR-000005-mtproxy-flow.puml) (первичная диаграмма — [ADR-000005](../ADR/ADR-000005.md))

1. Telegram-клиент подключается к access-узлу на порт 443 с fake-TLS SNI, равным домену из секрета. Умолчание — `max.ru`, inventory может его переопределить. Межузловое реле использует тот же домен; дополнительные публичные имена прокси не меняют домен внутри секрета.
2. nginx SNI Router анализирует SNI и маршрутизирует подключение на локальный порт mtg (2083).
3. mtg выполняет fake-TLS handshake, декапсулирует MTProxy-трафик и проксирует его к серверам Telegram.

### Конфигурация mtg

| Параметр | Значение | Описание |
|---|---|---|
| `secret` | Генерируемый при развёртывании | MTProxy secret для аутентификации |
| `bind-to` | `127.0.0.1:{{ mtproxy_local_port }}` — по умолчанию 2083 | Служба слушает только петлевой адрес: снаружи её порт не открыт, поток приходит от маршрутизатора SNI того же узла |
| `mtproxy_fake_tls_domain` | `max.ru`, можно переопределить в inventory | Домен fake-TLS, кодируется в общем секрете кластера |
| — | — | Порта маскировки в конфигурации нет: клиент подключается к порту 443, которым распоряжается маршрутизатор SNI, и тот направляет поток службе по имени SNI |
| Формат конфигурации | TOML | `mtg.toml` |
| Управление процессом | systemd | `mtg.service` |

### Маршрутизация nginx

nginx stream-модуль маршрутизирует подключения на порт 443 по SNI:
- SNI = домен маскировки MTProxy → `127.0.0.1:2083` (mtg)
- SNI = прочие → upstream Squid HTTPS port или default backend

**Защита секретов** (решение владельца, 2026-08-29): защищённое хранилище Ansible
не задействовано намеренно. Действующая мера — исключение рабочего инвентори из
контроля версий и права доступа к файлу; признана достаточной для одного оператора
на собственной управляющей машине. Хранилище добавило бы пароль при каждом прогоне,
не меняя модели угроз: доступ к машине оператора даёт и то и другое.

## Доказательство реализации

### Конструктивное

Реализовано через Ansible-роль `mtproxy`:
- Шаблон `mtg.toml.j2` генерирует конфигурацию из трёх параметров: секрет, адрес
  прослушивания (петлевой) и домен маскировки. Параметров `cloak_host` и `cloak_port`
  в ней нет — маскировкой ведает единственный параметр домена, а разбор имени выполняет
  маршрутизатор узла до передачи обращения службе.
- Systemd unit `mtg.service` управляет жизненным циклом процесса.
- Ansible-роль `nginx` конфигурирует stream-блок с `ssl_preread` и `map $ssl_preread_server_name` для SNI-маршрутизации.

### Аналитическое

**Выбор mtg v2:** единственная зрелая реализация MTProxy на Go с поддержкой fake-TLS. Оригинальный C-клиент от Telegram устарел и не поддерживает fake-TLS.

**Выбор порта 2083:** нестандартный порт для MTProxy, снижающий вероятность конфликтов. Внешний трафик приходит на 443 и маршрутизируется nginx.

**Маскировка под TLS к постороннему домену:** обмен выглядит как обращение к стороннему сайту по защищённому соединению, что затрудняет фильтрацию по признакам протокола. Правдоподобность маскировки определяется выбором домена: он должен быть таким, обращение к которому из сети клиента не вызывает вопросов. Выбор — за оператором, в репозиторий действующее значение не вносится.
